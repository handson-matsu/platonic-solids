# かたちのラボ — platonic-solids

正多面体を回して、塗って、つなぐ、日本語の3D数学教材です。5つの正多面体 × 4つの課題、計20チャレンジをブラウザだけで実行します。

## 起動

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。ES modulesを使うため、HTMLを `file://` で直接開かずHTTPで配信してください。ビルド・npm installは不要です。

## GitHub Pagesで公開

1. このリポジトリをGitHubの `platonic-solids` にpushします。
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. `main` へのpush、または **Actions → Test and deploy GitHub Pages → Run workflow** で公開します。
4. 公開先は通常 `https://<ユーザー名>.github.io/platonic-solids/` です。

ワークフローはテストが成功した場合だけ公開します。すべて相対パスで、リポジトリ名のサブパスでも動作します。既定ブランチが `main` 以外の場合はワークフローの `branches` を変更してください。GitHubへのpush・Pages設定・実際の公開はまだ実施していません。

## 遊び方

- 最初に正多面体とチャレンジを選んで開始。
- マウス／指のドラッグで回転。ホイール／2本指のピンチ／＋−ボタンで拡大縮小。
- 頂点・辺・面をタップして選択中の色を適用。消しゴムで未彩色に戻せます。
- 閉路では辺をタップすると選択／解除。選択辺は緑色かつ太線になります。
- 判定は「答え合わせ」を押したときだけ。使用色数や彩色済み数は進捗であり、操作中の正誤判定はしません。
- ひとつ戻す、リセットに対応。リセット自体も戻せます。立体・課題の変更時は新しい状態になります。
- 達成状況の一覧から20チャレンジを選択できます。
- キーボードではcanvasにフォーカスして矢印キーで回転、＋−で拡大縮小。「番号で選択する」から対象番号・隣接番号・現在色を確認して塗ることもできます。

クリア状況は `localStorage` の `platonic-solids:clears:v1` に保存します。解きかけの彩色・カメラ位置は保存しません。保存できないブラウザでは通知し、その画面を開いている間だけ記録を保持します。端末・ブラウザ・配信元ごとに独立し、アカウントやサーバーは使いません。同一オリジンの複数タブでは直近の保存内容に同期します。

## 数学的な構造と判定

実行時には `solids.js` に格納した明示的な頂点座標・辺の両端・面の頂点順・3種類の隣接リストを使います。画面上の距離、色、メッシュの見た目から隣接を推測しません。五角形と四角形の内部三角分割は描画専用で、彩色・判定は元の面ID単位です。

`scripts/generate-solids.py` は正多面体の標準座標（黄金比を含む）から支持平面を求める**開発時専用**の再生成ツールです。出力をデータとしてリポジトリに固定しています。再生成は `python3 scripts/generate-solids.py`。

<details>
<summary>教員・開発者向け：最小色数（ネタバレ）</summary>

| 正多面体 | 頂点彩色 | 辺彩色 | 面彩色 |
|---|---:|---:|---:|
| 正四面体 | 4 | 3 | 4 |
| 立方体 | 2 | 3 | 3 |
| 正八面体 | 3 | 4 | 2 |
| 正十二面体 | 3 | 3 | 4 |
| 正二十面体 | 4 | 5 | 3 |

頂点彩色は元のグラフ、辺彩色は線グラフ、面彩色は双対グラフの頂点彩色として扱います。テストではDSATUR順序付けによる厳密バックトラック探索で、各値における彩色の存在と、1色少ない彩色の不存在を確認します。色の名前の置換だけを対称性除去するため、可能な彩色を取りこぼしません。

ハミルトン閉路は未到達頂点の有無、各頂点の選択辺次数が2、選択部分グラフの連結性を検査します。複数の閉路に分かれた2正則グラフは不合格です。

## 選択と操作の実装

Three.js 0.180.0を `vendor/` に同梱し、外部CDN・外部フォント・APIへのアクセスはありません。

- 頂点・辺のヒット領域は画面上のCSSピクセル基準。表示サイズに左右されないタッチ許容幅です。
- 凸多面体の支持平面とカメラ位置を用いて背面を除外。面はRaycasterで最前面の面IDを取得します。
- 7 CSS pxを超えたドラッグは元の位置に戻ってもタップにしません。
- 複数ポインター、キャンセル、キャプチャ喪失はタップ候補を無効化します。
- カメラ移動・操作時のみ描画し、常時アニメーションループは動かしません。

Three.jsの[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[Raycaster](https://threejs.org/docs/pages/Raycaster.html)を使用しています。ライセンスは `vendor/THREE-LICENSE.txt`（MIT）です。

## テスト

Node.js 22以上で実行します。外部テストパッケージのインストールは不要です。

```sh
npm test
# または
node --test tests/*.test.js
```

検証内容：

- 5種類のV/E/F、Eulerの関係、辺長、面境界、各辺に接する2面、隣接関係。
- スマートフォン幅375とPC幅1100で、全ての頂点・辺・面を正面に向けて個別に選択。
- 背面頂点・背面辺の除外、ドラッグ・マルチタッチ・キャンセルの誤彩色防止。
- 15種類の最小色数の厳密確認、未彩色・衝突・非最小彩色の判定。
- 5種類すべてのハミルトン閉路、未到達・次数不正・複数閉路の判定。
- 全20件の保存と復元、破損JSON、不正データ、保存不可への対応。

モバイル向けレイアウトと選択ロジックを検証していますが、iPhone・Android・iPadの実機タッチ操作を保証するものではありません。公開前に利用予定の実機でも回転、ピンチ、画面端のタップをご確認ください。
